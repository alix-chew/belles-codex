# Blue Ocean Kopi & Co.

A warm, modern single-page website for **Blue Ocean Kopi & Co.**, a neighbourhood plant-based cafe at YKK Street in Singapore.

## Stack

- Vite
- React
- Tailwind CSS
- lucide-react icons

## Run Locally

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Notes

The page uses cropped images rendered from the assignment PDF and stored in `public/images/`.

The pitch PRD is saved as `Blue_Ocean_Kopi_PRD_Pitch.pdf`.
